# Leitlinien_Uni_HD

Dieser Ordner ist im Repo absichtlich leer. Die beiden maßgeblichen Regelwerke
sind offizielle Dokumente der Universität Heidelberg und werden hier nicht
weiterverbreitet:

- Abfassungsrichtlinien der Medizinischen Fakultät (Dateiname mit Datum und
  Version, z. B. `2026_10_02_Abfassungsrichtlinien_Version_2_5.pdf`):
  https://www.medizinische-fakultaet-hd.uni-heidelberg.de/fakultaet/akademische-laufbahn/promotion/promotion-zum-dr-sc-hum/schreiben-der-dissertation
- KI-Leitlinie der Universität Heidelberg (`ki-leitlinie-de.pdf`):
  https://www.uni-heidelberg.de/md/zaw/ufg/informationen/ki-leitlinie-de.pdf

`/start` (Schritt 2) lädt die jeweils aktuelle Fassung hierher, damit Claude
darin nachlesen kann. Alle Dateien außer dieser README sind per `.gitignore`
vom Commit ausgeschlossen. Vor der Abgabe prüfen, ob die lokale Kopie noch die
aktuelle Version ist.
